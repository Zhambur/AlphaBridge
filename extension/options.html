AlphaBridge

在 alphaXiv 阅读，正文逐句对照，划词写批注。

翻译与对话服务

使用兼容 Chat Completions 的接口。翻译时发送正文句子；对话时先发送 arXiv 编号、当前引用和历史，再由模型调用工具按需读取原文。问答需要接口支持 tools / tool_choice；费用取决于你配置的服务。未配置时仍可阅读和批注。

密钥仅保存在当前浏览器扩展存储中，不写入网页和 Obsidian。留空保持原密钥。

Obsidian

选择仓库根目录，插件会直接写入 Markdown，无需安装本机桥接。

浏览器不会允许插件按输入的路径自动获得权限。首次使用须选择一次含 .obsidian 的目录；权限失效时重新授权。子目录和名称修改后点击上方“保存设置”。

PDF 缓存

PDF 在插件内下载、渲染和裁剪，无需 Python。最多缓存六篇 PDF。

阅读方式

在 alphaXiv 论文页面点右下角“双语原文”。使用 arXiv / ar5iv 的 HTML 原文保留图表、MathML 公式和引用，英文每句下方显示译文。HTML 会重新排版，与 PDF 页码不一一对应。

正文、摘要和图注支持逐句翻译；图中和表格单元格里的文字、参考文献保留原文。没有 HTML 的论文继续在 alphaXiv 阅读 PDF，选中文字后仍可写批注。

选中文字后就地输入想法，点“保存到 Obsidian”。保存失败时草稿保留，可从阅读页“批注”中重试。网页更新可能影响插件入口；不会修改云端收藏。
